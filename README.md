# CodeAlpha_Calculator

Calculator built with HTML, CSS and vanilla JavaScript (CodeAlpha Frontend Internship – Task 2).

## Features
- Operations: + − × ÷, plus %, ± and decimals
- Buttons with display screen, clear (AC), backspace
- Real-time display and expression history
- Divide-by-zero handling, no `eval()` used
- Bonus: full keyboard support (0-9, + - * /, Enter, Backspace, Esc) and styled UI

## Run
Open `index.html` in a browser.
